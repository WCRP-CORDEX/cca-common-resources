# CORDEX Coordinated Analyses: common resources

This repository holds common resources and discussion regarding the CORDEX coordinated cross-domain analyses organized during the [CORDEX International Workshop on Coordinated Regional Projection Research and Synthesis](https://indico.ictp.it/event/11298), held in Trieste on 11-15 May 2026.

Use this repository only for common code and other resources and for general [discussion](https://github.com/WCRP-CORDEX/cca-common-resources/issues).

Go to the repository for individual analyses for specific code and discussion (some of them are private):

| Analysis | Repository | Private |
|----------|------------|---------|
| Urban heat stress | https://github.com/WCRP-CORDEX/cca-urban-heat-stress | yes |
| Extreme precipitation | https://github.com/WCRP-CORDEX/cca-extreme-precipitation | yes |
